# Welcome to My Blog 

This blog is built with a minimalistic approach, focusing on content and ease of use.
It leverages GitHub (Pages) for hosting, compiling (static pages), and serving pages.
You are free to fork the project and reuse it as much as you want.

## Partly vibecoded, partly inspired by others' work 

### Clean Design

It features a clean, minimalistic design with:

- Generous white space for better readability
- Responsive layout that works on all devices
- Clear typography and comfortable line spacing

### Search

There is a **large, prominent search bar** at the top of every page. 
You can quickly find any content across all blog posts and pages using keywords.

### Easy Content Management

All content is written in Markdown and stored in the same GitHub repo. 
To add a new blog post:

1. Create a new `.md` file in `content/posts/`
2. Use the naming format: `YYYY-MM-DD-title.md`
3. Add YAML front matter with title, date, and tags
4. Write your content in Markdown
5. Push to GitHub (and the static site will rebuild automatically)

## Built With

- **Pandoc**: Converts Markdown to HTML
- **Lunr.js**: Powers the client-side search functionality
- **GitHub Pages**: Free, reliable hosting
- **GitHub Actions**: Automatic deployment on every push
